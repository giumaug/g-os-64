g-os-64 memory layout
kernel physical address 0x100000   (1M) 
kernel virtual address  0x400000000 (16G)
process_virtual_address 0x100000 (size: 1G - 8G)
process_heap_virtual_address 0x200000000 (size: 8G - 15G)
kernel_virtual_stack 0x3FFCFF000 (16G - 3M - 4k hole; size = 0x2000)
user_virtual_stack  0x3FFCFC000 (16G - 3M - 4K hole - 8K - 4K hole;size 0x40000000)

kernel_virtual_stack 0x3FFFFF000 (16G - 4k hole; size = 0x2000)
user_virtual_stack  0x3FFFFC000 (16G - 4K hole - 8K - 4K hole;size 0x40000000)

30300000 8254x MEMORY 0x10000
30310000 AHCI MEMORY 0x2000
30312000 IOAPIC 0x1000
30313000 LAPIC 0x1000
 
Temp mapping
kernel mapping 16G - 16G + 2M -> 1M - 3M
loader mapping 0M - 38M -> 0M - 38M (loader at 1M, 34MB for final master page table) 

Final mapping
kernel mapping 16G - 16G + 1M -> 1M - 3M
kernel master page table 16G + 4M (-) 16G + 38M -> 4M - 38M (WROST CASE)

33 MB for master page mapping 16G
4096+4096+(4096*16)+16*(4096*512)
